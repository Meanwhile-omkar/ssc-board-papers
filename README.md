# Maharashtra SSC (Class 10) Board Papers – 2019 to 2026

Free past board question papers (PYQs), prelim papers and SCERT question banks for the Maharashtra State Board SSC exam, in English and Marathi medium.

**Easiest way to use this:** go to **[omkarharyan.paperkitelabs.com/ssc-boards-pyqs](https://omkarharyan.paperkitelabs.com/ssc-boards-pyqs)**. You can filter by medium, subject and year there, in English or Marathi.

To get every paper at once, use **Code → Download ZIP** on GitHub.

## What's inside

```
PYQ-Papers/
  2026/
    English Medium/      Maths 1, Maths 2, Science 1, Science 2, History, Geography
    Marathi Medium/      the same subjects in Marathi medium
    Hindi Medium/  Urdu Medium/  Kannada Medium/   (where the board printed them)
    Language Papers/     Marathi, Hindi, English, Sanskrit, Urdu, Arabic, German
    Supplementary Exam - June 2026/
  2025/  2024/  2023/  2022/  2020/  2019/   (same layout)
Model-Question-Papers/
  Prelim and Practice Papers/   full prelim exams from schools (2025-26, 2024-25, 2018-19)
  Question Banks (SCERT Maharashtra)/   2022 and 2023, English and Marathi medium
catalog.json   one entry per file: year, exam, medium, subject, board paper code, pages
```

File names look like `SSC March 2026 - Maths 1 Algebra - Marathi Medium.pdf`.

## Notes

- Every board paper was checked against the paper code (for example N 919) and the exam date printed on it.
- There are no 2021 papers, because the 2021 SSC exam was cancelled due to COVID. The March 2020 Geography paper was cancelled too.
- Language papers are the same for every medium.

## Sources and credit

- **Board papers:** published by MSBSHSE (Maharashtra State Board of Secondary and Higher Secondary Education).
- **Scans:** collected from maharashtrastudy.com, AglaSem, CareerIndia and Careers360.
- **Question banks:** from SCERT Maharashtra.
